        prob de que seu modelo explique a variavel buscada.

        quando maior o r2, melhor seu modelo representa a variabilidade da populacao comparado a media.
                                                                                                invariavel em relacao a variavel de interesse
    erro medio absoluto (mae), 

        Mede a media da diferenca absoluta entre os valores previstos pelo modelo e os valores observados.
        ou

    erro medio quadratico (mse),

        comum em verificacao de acuracia de modelos, dando maior peso a maiores erros
        cada erro é elevado ao quadrado individualmente, seguido da media dos erros
        Quanto maior a distancia, maior o erro da amostra.


    raiz do erro quadratico medio (rmse), 
        raiz quadrada do mse - diminui a penalidade sobre o valor total de mse

    erro percentual absoluto medio (mape)
        erro é medido em porcentagem
        media(erro absoluto/observado para cada amostra).100%

classificacao

Se baseia em matriz de confusao (++, +-, -+, --) x = predito, y = real
                VERDADEIROS
    acuracia -   VP + VN  / TODOS
    proporcao de gatos e nao gatos corretamente classificados

    precision - VP / POSITIVOS (VN + FP)
    proporcao dos dados classificados como gatos realmente eram. Foco no falso +. Todo - realmente é -, mesmo
    que tenha falso -.

    recall (sensibilidade) = VP / VP + FN
    dentre todos os classificados como gatos (+), qual a proporcao de verdadeiros +. foco no falso -. Todo +
    realmente é +, mesmo que tenha falsos +.

    f1 score = Precision x Recall / Precision + Recall
    Observacao de precisao e recall em um unico numero - um equilibrio das duas mais opostas

clusterizacao

Nao sei a classe, e quais sao as classes. O modelo vai agrupar por semelhanca.

    harabasz - extrinseco. ajuda a identificar o numero ideal de clusters (k) em casos nao supervisionados
        verifica a densidade e distancia entre clusters (foco extrinsico)
        quanto maior esse valor, mais bem separados os clusters

    davies bouldin - extrinseco. avalia separacao de clusters e a compactacao.
        verifica a distancia entre amostras de um cluster, e alem disso, calcula a distancia do centroide do cluster 
        em comparacao com as amostras do outro grupo.
        Quanto maior, maior separacao de clusteres+compactacao de grupo

    silhouette - intrinsico. mede a semelhanca de um ponto de dados a seu proprio cluster e com outros clusters.
        Mede mais a uniformidade do cluster do que a distancia entre clusters. Se mais disperso o cluster,
        menor a silhouete.
        prox de +1 - excelente ajuste. amostras muito uniformes e grupos distantes
        prox de -1 - a amostras deve ter sido classificada errada, pois esta mais proxima de outros clusters
        do que do que esta classificados
        prox de 0 - a amostra esta entre medidas de clusters. nao ha clusters bem difinidos

    ari (adjusted rand index) - extrinseco. para analise supervisionada
        avalia com base em um cluster conhecido. calcula a aplicacao correta das amostras por cluster rotulado
        1 = agrupamento perfeito
        0 - agrupamento sem sentido
        -1 - 
        para cada ponto, ele calcula a distancia da amostra para o cluster que ele deveria estar (diferente dos 
        outros ele nao faz calculo entre amostras)

    ami (adjusted mutual information) - extrinseco. tambem supervisionados
        nao calcula entre cluster, so observa o erro dentro de cada grupo.        
         1 = agrupamento perfeito
        0 - agrupamento sem sentido
        -1 -

Clusterizacao - nao supervisionada

k-means - 1o algoritmo de clusterizacao. particiona dados em k clusters. atribui pontos a um centroide e em seguida recalcula 
as distancias. faz isso iterativamente ate minimizar ao maximo as distancias ao centroide

Hiperparametros - (parametro - o que entregamos para uma funcao trabalhar) sao o que entregamos para o algoritmo performar.
São ordens/caracteristicas que entregamos para o algoritmo performar.

k => hiperparametro NUMERO DE CLUSTERS

Determina o minimo e maximo das duas variaveis do caso e chuta um valor intermediario (centroide 1)
Em seguida, calcula a distancia euclideana do centroide para todos os outros pontos e tira a media (media do erro)
Numa segunda iteracao, ele chuta outro centroide e calcula o erro, e faz isso continuamente ate encontrar um centroide com 
menor erro possível.

Metodos para estimar k

inercia - base do metodo do cootvelo. mede a compactacao do cluster a partir do erro/media.
No grafico n clusters X inertia testamos os K onde ha o ponto de inflexao da curva (cotovelo)

silhueta media - no grafico n de clusters X silhueta media - quanto maior o valor, melhor. Indica a condensacao dos grupos.

BOXPLOT - é interessante observar os grupos em boxplot para a 2 variaveis de interesse, e observar se elas realmente sao
distintas pela variacao de x e y.

Nao performa bem em mais de 2 variaveis

dbscan

agrupamento com base na densidade dos dados. infere os grupos, nao é um hiperparametro.
EPSILON = hiperparametro que define um raio especifico de vizinhos por grupo (dentro desse raio epsilon, o erro deve ter um valor
menor que epsilon). Distancia maxima para que dois pontos sejam vizinhos (do mesmo cluster)
MIN_SAMPLES - Numero minimo de amostras em uma vizinhanca para que seja considerado um centroide.

Aceita ruido (nao classificados)

Ele comeca com um centroide aleatorio. Se ele for um ponto central (se ele encontrar pontos dentro do epsilon), ele se torna 
um cluster. Ele cria novos centroides ate que a maior parte dos pontos sejam encontrados.

Valores de cluster negativos na verdade sao o grupo de amostras ruido!

Agrupamento hierarquico

Constroi dendrograma. nao requer grupos pre definidos, forma uma arvore para ser posteriormeente cortada

Calcula a similaridade de todos os pontos entre si, e depois organiza grupos animnados.

Hiperparametros: ambos definem limites de fusao de grupos
N_CLUSTERS. Padrao 2
DISTANCE_THRESHOLD. Distancia maxima na qual dos grupos devem ser ser unidos (default None)
LINKAGE - metodo de ligacao de grupos. default Ward
METRIC - como o algoritmo mede o espaco entre pontos. default = euclideana

Devemos sempre analisar a arvore visualmente para determinar os grupos

K-Nearest neighbors
Algoritmo nao parametrico (nao requer normal). classifica um novo ponto de dados com base na classe majoritaria dos seus 'k' 
vizinhos. calcula a distancia entre esses vizinhos e atribui a classe mais comum no grupo.

Metrica - matriz de confusao! acuracia (proporcao de valores corretamente classificados), precisao (preocupação
maior com valores realmente positivos), recall (prioriza os realmente negativos) e f1 score (maneira de observar em um unico
numero precisao e recall).

Regressao logistica

Preve a probabilidade de um resultado categorico com base em variaveis independentes em SIGMOIDE.
O ponto de inflexao da sigmoide é o divisor das duas classes (50%)

Um pouco de probabilidade - se aplica a todos os modelos

Probabilidade = qual a prob de um valor max ou min dos dados estar presente em uma amostragem?

Risco do evento (risk event) = qual a prob de um vaor max ou min estar em uma classe determinada?

Chance do evento (odds) = qual a prob de um max ou min estar em alguma classe? (classificado ou ruido?)

Razao de chance do risco (odds ratio) = razao entre as chances de dois eventos estarem na classe

Logaritmo da chance (log ratio) = log neperiano da chance. para valores muito discrepantes

Forca explicativa (woe) = log neperiano da razao de chance. ex: a forca explicativa da classe x em relacao ao grupo 1 é menos
provavel para max (-0,25) do que para min (0,21). Representa a capacidade explicativa da classe sobre outra, ou a diferenca de 
uma classe sobre a outra.

coef - coeficiente beta para analise (inclinacao)

SVM - Support Vector Machine

para tarefas de classificacao e regressao. Funciona encontrando um hiperplano, para dados que nao podem ser 
separados linearmente! Utiliza um kernel (transforma dados). Pontos mais proximos da classe so assim classificados.

Tracamos um conjunto de linhas para separar grupos, mas a posicao delas pode favorecer uma ou outra classe (por area de 
grafico pra cada classe)! A maquina de suporte fara isso iterativamente para detectar a linha mais favoravel, e para
alem da linha, manipula as duas dimensoes, criando uma 3a dimensao ficticia (matematica, o kernel), e manipula a posicao 
relativa desses dados para separa-los da melhor forma (ao inves de linha, o HIPERPLANO)

Hiperparametros

´POLY = kernel de dados nao lineares, relacoes curvas mais complexas

Redes neurais

Para regressao, o output é modificado. O compilador retora os valores de interesse.
A ultima camada sera sempre 1, se for classificacao, o n de classes sera o numero de neuronios de saida

Loss - indica a aprendizagem, a diminiuicao progressiva da perda é importante para indicar aprendizagem.
MAE - taxa de erro.

Redes neurais sao um sistema de algoritmos, pois diferente dos demais ele nao aplica uma equacao para descrever os dados,
mas cada neuronio da rede é uma equacao com:

        NEURONIO 1
input . peso . taxa de aprendizagem -> funcao de ativacao -> output
Y = B(random) + wx (peso. var ind=input) + b (bias - taxa de erro, variacao adicional para ajuste)

        NEURONIO 2                  |
input . peso . taxa de aprendizagem |

MATRIZ DE NEURONIOS SE SOMAM PARA FUNCAO DE ATIVACAO -> OUTPUT
O valor do neuronio (Y) sera jogado para a saida, e sera propagado se passar o threshold da funcao de ativacao

na camada final, a saida sera o numero de respostas. Se regressao, 1, se classificacao, n classes...
A funcao de ativacao vai determinar se um neuronio deve ser ativado ou nao, transformando a entrada ponderada em um sinal 
de saida. Esta funcao pode ser de varios tipos (sigmoide, tangente...), onde cair o valor do neuronio, definimos se vai se propagar
ou nao

Havendo propagacao, o neuronio passa para todos os neuronios da camada interna a ele utiliza o Y da anterior como x na nova camada.
Se chegarem 2 Y da camada anterior, ele fara o calculo da sua equacao. Se 2 valores passarem pela funcao de ativacao, ele fara
uma media, propagando para todos os neuronios da camada seguinte.

Algoritmo de otimizacao - BACKPROPAGATION
Apos a corrida ate a camada de saida, ele calculara o erro das predicoes com o observado (rotulo). Com esse erro, ele fara todo 
o caminho de volta e gera novos valores para cada neuronio das camadas anteriores (cada neuronio tem seus valores aleatorios unicos).
Corre novamente e calcula o erro, calculando o residuo (diferenca dos erros). A ideia e minimizar o residuo.

A determinacao da melhor topologia é testada manualmente, nao tem como usar o GridSearch, exceto se for uma pre-determinada.

A perda sera o nivel de ajuste de residuos de erro. Conforme o residuo é minimizado, a perda diminui.

O reajuste dos neuronios durante o backpropagation sera feito com base no residuo, e a funcao de otimizacao impede com que ele 
simplesmente siga diminuindo o erro, a fim de evitar que ele se perca em um minimo local (vale), e nao buscar o minimo do residuo
global.
O ajuste das variaveis dos neuronios é feito por um vetor chamado GRADIENTE

    Tipos de algoritmos de otimizacao
    SGD
    SGD com momentum
    Adam - mais utilizado

Hiperparametros
Funcao de Perda (metrics)= regressao(erro quadratico medio, erro abs medio), class(entropia cruzada binaria- 2 classes, 
categorical class entropy - quando tem mais de 2 classes). 
Metrica - quais metricas de avaliacao a utilizar (varia se regressao ou classificacao)
epochs = quantas sao as rodadas de foward e backpropagation
batch=size = numero de exemplos de treinamento usados na iteracao (sub-amostragem e treino = cross_validation em outros algoritmos)
verbose = envio de mensagens durante a execucao

#Aula producao

POO - programacao orientada a objetos utilizando classes e objetos para organizacao de sistemas complexos

Conceitos basicos

Classe: molde ou planta de um objeto - ex: a ideia de um carro
Metodo: uma funcao, uma acao associada a uma classe. Ex: read_csv(). Pode receber argumentos!

O metodo é uma funcao inerente da classe, é basica. Se a funcao for externa a classe, é uma funcao

Atributo: caracteristica associada a uma classe. Ex: shape. Nao recebe argumentos

Toda biblioteca É uma classe

Abstracao: o que algo precisa ter para ser daquela classe. Ideias basicas de um objeto pertencente a uma classe

Objeto: instancia da classe. criacao real baseada na classe.

4 pilares da POO

    - Encapsulamento - escondemos os detalhes internos de funcionamento e mostrar somente o necessario. Controla o trabalho
    - Heranca - passar as caracteristicas e metodos de uma classe pai para um classe filha para evitar redundancias
    - polimorfismo - permite que a mesma funcao funcione de formas diferentes dependendo do objeto que executado
    - abstracao - focar apenas no que e essencial para o problema no momento

Cada metodo, portanto, deve fazer apenas uma coisa sobre a entrada, e devolver apenas uma coisa!

Ao criar uma classe, temos que incluir os metodos e atributos dessa classe. É uma boa pratica sempre testarmos os metodos conforme 
os criamos. Para isso podemos aplicar testagens automatizadas. 

Testagem automatizada
Uso de programas e ferramentas para testagem dos metodos aplicados. Podem ser

Testes unitarios - validam pequenas partes isoladas do cogido, como unicad funcao
Testes de integracao - verificam se diferentes partes do sistema ou servicos funcionam bem juntos
Testes ponta a ponta - simulacao real do usuario na tela do sistema do comeco ao fim

ao diferenciar um metodo e funcao, temos Sempre

METODO = inerente da classe, estara na criacao da classe e recebe parametro SELF. SELF determina para o python que este metodo É
exclusivo da classe!

metodo(self, param1, param2)

FUNCAO - nao tera o parametro self na sua descricao!!

funcao(param1, param2)

CI/CD - integracao continua, continua entrega (deploy)

O conceito de integracao continua envolve
Envio constante - devs mandam pequenas alteracoes de codigo varias vezes ao diante
Testes automaticos - cada alteracao roda testes de unidade e integracao para achar erros logo no intrinsico
